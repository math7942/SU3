14단계 · Skills로 한글(HWP) 문서 다루기

학교 문서 대부분이 한글(HWP·HWPX) 파일이라는 점에 맞춰, 클로드에 스킬을 켜서 HWP 문서를 읽고 채우고 고치는 법입니다.

1. Skills(스킬)이란

Skills는 클로드에 추가로 켤 수 있는 전문 기능 꾸러미입니다. 11단계에서 배운 Projects가 "지침과 자료를 모아두는 공간"이라면, Skills는 "클로드가 원래 못 하던 특정 작업을 할 수 있게 해주는 도구"에 가깝습니다. 한 번 켜두면 그 뒤로는 대화창에서 그냥 요청하기만 하면 됩니다.

2. 왜 한글(HWP) 스킬이 필요한가

학교에서 주고받는 공문, 가정통신문, 평가계획서, 각종 서식은 대부분 .hwp 또는 .hwpx 파일입니다. 이 형식은 워드(.docx)와 달라서, 스킬이 없으면 클로드가 파일을 열어도 내용을 제대로 읽지 못하거나 표·서식이 깨질 수 있습니다. hwp-hwpx 같은 스킬을 켜두면, 한글 프로그램이 설치되어 있지 않은 컴퓨터에서도 클로드가 파일 내용을 정확히 읽고, 필요하면 직접 수정까지 해서 돌려줍니다.

3. 무엇까지 할 수 있나

파일 형식읽기편집 · 양식 채우기
.hwpx (2014년 이후, 최신 형식) ✅ 표·문단 포함 전체 지원 ✅ 찾아 바꾸기, 여러 문단 채우기, 표 값 수정까지 지원
.hwp (예전 형식) ✅ 텍스트 추출 가능 △ 직접 편집은 제한적 — 보통 .hwpx로 저장해 다시 요청하면 편집까지 가능합니다

모르면 일단 물어보세요

파일을 첨부하고 "이 파일이 어떤 형식인지, 편집까지 가능한지 확인해줘"라고 먼저 물어보면 클로드가 스킬로 파일을 열어본 뒤 가능한 작업을 알려줍니다.

4. 스킬 켜는 법

  1. 클로드 화면 오른쪽 위 설정(또는 기능) 메뉴에서 "Skills"로 들어갑니다.
  2. 목록에서 hwp-hwpx를 찾아 토글을 켭니다.
  3. 이후 새로 시작하는 대화부터 .hwp·.hwpx 파일을 첨부하면 자동으로 이 스킬을 써서 내용을 읽습니다.

학교 계정이라면 먼저 확인하세요

학교나 교육청에서 관리하는 워크스페이스 계정은 관리자가 스킬 사용을 막아뒀을 수 있습니다. 목록에 hwp-hwpx가 보이지 않는다면 관리자에게 스킬 사용 가능 여부를 먼저 문의하세요.

1단계 · 클로드로 무엇을 할 수 있나

수학교사가 실제로 하는 업무를 기준으로, 클로드의 어떤 기능을 쓰면 되는지 먼저 지도를 그려봅니다. 관심 있는 항목을 누르면 그 업무를 배우는 단계로 바로 이동합니다.

아직 클로드가 낯설다면

먼저 2단계 — 가입과 화면 익히기로 시작해서 3단계 — 질문을 잘하는 법까지 익힌 뒤, 아래 지도로 돌아와 필요한 업무를 골라 이어가는 것을 추천합니다.

🔍

답 검증하기 → 클로드가 낸 계산·풀이를 검산하는 습관

수업에 쓰기 전, 클로드의 답을 믿고 그대로 쓰지 않고 확인하는 법입니다.

 4단계로 이동 🗒️

대화(채팅) → 평가계획서·수업계획 초안 작성

성취기준을 붙여넣고 평가계획서, 진도표, 지도안 초안을 받습니다.

 5단계로 이동 📝

프롬프트 작성 → 시험문제 만들기

난이도별 객관식·단답형 문제를 만들고 기출문제를 변형합니다.

 6단계로 이동 📐

서술형 문항 → 채점 기준(루브릭) 만들기

서술형 문제와 배점 기준표를 함께 만들고 예시 답안으로 검증합니다.

 7단계로 이동 🔒

학생 자료 → 안전하게 다루기

학생 답안을 올리기 전에 개인정보를 익명화하는 법과 주의사항입니다.

 8단계로 이동 🖼️

이미지·파일 업로드 → 서술형 평가 채점

손글씨 풀이나 시험지를 사진·PDF로 올려 채점받고 근거를 확인합니다.

 9단계로 이동 💌

문서 작성 → 학생 피드백·생기부 문구

채점 결과를 바탕으로 학생별 맞춤 피드백과 생기부 문구를 다듬습니다.

 10단계로 이동 🗂️

Projects → 학급별·학기별 자료 정리

대화와 파일을 묶어 학기 내내 이어서 쓰고, 반복 지침을 저장합니다.

 11단계로 이동 🧩

Artifacts → 인터랙티브 수업 도구 제작

그래프, 도형, 퀴즈처럼 바로 실행되는 결과물을 만들어 수업에 씁니다.

 12단계로 이동 💻

코드 실행(Analysis) → 계산·시각화 자동화

클로드가 직접 코드를 짜고 실행해 계산과 시각화, 자동 채점을 돕습니다.

 13단계로 이동 📄

Skills → 한글(HWP) 문서 읽고 편집하기

스킬을 켜서 .hwp·.hwpx 문서를 읽고, 양식을 채우고, 표를 고칩니다.

 14단계로 이동 🔁

반복 업무 → 자동화로 굳히기

성적 처리, 시험범위 수합 같은 반복 업무를 템플릿·스크립트로 만듭니다.

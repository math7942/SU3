13단계 · 코드 사용법

클로드가 직접 코드를 짜고 실행하게 해서 계산 자동화와 시각화, 자동 채점 프로그램을 만듭니다.

1. 코드 실행이 왜 유용한가

4단계에서 배웠듯, 클로드가 말로 계산하면 실수할 여지가 있습니다. 반면 코드를 직접 작성해서 실행하면 컴퓨터가 정확하게 계산하므로, 특히 숫자가 많거나 반복이 필요한 작업에서 훨씬 믿을 수 있는 결과를 얻습니다.

2. 언제 코드 실행을 쓰면 좋은가

상황이유
큰 데이터의 통계 계산 (학급 전체 평균·표준편차)사람이 손으로 하면 실수하기 쉬운 계산을 정확하게 처리합니다.
여러 조건의 경우의 수 세기가능한 경우를 빠짐없이 전부 나열해서 셀 수 있습니다.
그래프·시각화 자료 만들기정확한 좌표로 그래프를 그려줍니다.
반복적인 파일 처리 (8단계의 이름 익명화 등)여러 데이터를 한 번에 같은 규칙으로 일관되게 처리합니다.

3. 요청하는 법

코드를 몰라도 괜찮습니다. 원하는 계산이나 처리 내용을 말로 설명하면, 클로드가 스스로 코드를 작성하고 실행해서 결과만 보여줍니다.

프롬프트 예시

"우리 반 32명의 수학 점수야: [점수 목록]. 코드를 실행해서 평균, 표준편차, 최고점, 최저점을 정확히 계산하고 히스토그램도 그려줘."

실습

평균·표준편차 계산기

쉼표로 구분한 점수를 넣으면, 코드 실행이 실제로 어떤 결과를 돌려주는지 이 페이지에서 바로 계산해 보여줍니다.

4. 결과 확인하기

코드 자체를 이해하지 못해도 괜찮지만, 나온 결과가 상식적인지는 확인하세요. 예를 들어 평균이 점수 범위 안에 들어오는지 정도는 눈으로 바로 확인할 수 있습니다. 궁금한 부분은 "이 코드에서 이 부분이 왜 이렇게 되어 있는지 설명해줘"라고 물어볼 수 있습니다.

다른 단계와 연결해서 활용하기

8단계의 학생 이름 익명화, 9단계의 여러 명 채점 결과 정리처럼 반복 작업이 필요한 곳에 코드 실행을 함께 쓰면 훨씬 빠르고 정확하게 처리할 수 있습니다.

5. 주의할 점

개인정보와 최종 검증은 그대로 적용됩니다

코드에 입력하는 데이터도 8단계의 익명화 기준을 먼저 확인하세요. 코드로 계산했다고 해서 검증이 필요 없는 것은 아니므로, 4단계에서 배운 대로 결과를 한 번 더 확인하는 습관을 유지하세요.

8단계 · 카드뉴스·인포그래픽으로 개념 설명하기

여러 장짜리 카드뉴스로 개념을 설명하고, Magic Charts로 데이터를 바로 인포그래픽으로 바꿉니다.

1. 카드뉴스란

카드뉴스는 정사각형 슬라이드 여러 장을 순서대로 넘겨보며 하나의 이야기를 전달하는 형식입니다. 개념 하나를 "질문 → 설명 → 예시 → 정리"처럼 몇 장으로 나눠 설명하면 학생이 훨씬 편하게 읽습니다. 학급 게시판이나 안내용 SNS 계정에 올리기도 좋습니다.

2. Magic Charts로 인포그래픽 만들기

왼쪽 사이드바의 "앱"에서 Magic Charts를 열고 표 데이터를 입력하거나 붙여넣으면, 막대·꺾은선·원형 그래프 중 어울리는 형태로 자동 디자인해줍니다. 성적 분포, 단원별 정답률 같은 데이터를 시각 자료로 바꿀 때 유용합니다.

3. 데이터로 막대그래프 미리 만들어보기

"항목:값" 형태로 데이터를 넣으면 이 페이지에서 바로 막대그래프를 그려주고, Magic Charts에 입력할 요청 문구도 함께 만들어줍니다.

실습

막대그래프 미리 보기

"항목:값"을 쉼표로 구분해 입력하세요.

4. 확인할 점

데이터와 색상 대비를 확인하세요

자동으로 만든 그래프도 숫자가 원본 데이터와 정확히 일치하는지 확인하세요. 색으로만 항목을 구분하면 색약인 학생은 읽기 어려울 수 있으니, 막대나 조각 위에 숫자를 직접 표시해두는 것이 좋습니다.

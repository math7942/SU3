Canva 🎨

1단계 · 캔바로 무엇을 할 수 있나

캔바는 학습지·발표자료·카드뉴스처럼 눈에 보이는 자료를 빠르게 만들고, 학생과 함께 실시간으로 편집할 수 있다는 점이 가장 큰 특징입니다. 관심 있는 항목을 누르면 그 업무를 배우는 단계로 바로 이동합니다.

아직 캔바가 낯설다면

먼저 2단계 — 가입과 화면 익히기로 시작해서 3단계 — 템플릿·브랜드 키트로 빠르게 시작하기까지 익힌 뒤, 아래 지도로 돌아와 필요한 업무를 골라 이어가는 것을 추천합니다.

✍️

Magic Write → 문구·설명 초안 쓰기

안내문이나 카드뉴스에 들어갈 문구를 자동으로 초안 작성합니다.

 4단계로 이동 🪄

Magic Design·Magic Media → 이미지·레이아웃 생성

글이나 이미지 설명만으로 디자인 초안과 그림을 만듭니다.

 5단계로 이동 📄

학습지·프린트물 → 디자인해서 인쇄하기

표·도형을 배치해 수학 학습지와 프린트물을 만듭니다.

 6단계로 이동 📽️

프레젠테이션 → 수업용 슬라이드 제작

발표자 노트까지 포함한 수업 슬라이드를 만듭니다.

 7단계로 이동 📊

카드뉴스·인포그래픽 → 개념을 한눈에 설명

Magic Charts로 데이터를 바로 인포그래픽으로 바꿉니다.

 8단계로 이동 🎯

인터랙티브 활동 → 참여형 학습 자료 제작

퀴즈·활동형 자료를 만들어 수업에 바로 씁니다.

 9단계로 이동 🤝

Canva Class → 학생과 함께 실시간 디자인

학급을 만들고 학생을 초대해 과제와 모둠 프로젝트를 진행합니다.

 10단계로 이동 🏫

Google Classroom 연동 → 과제 바로 배포

완성한 디자인을 다른 서비스로 바로 배포합니다.

 11단계로 이동 🔗

Claude·Gemini·ChatGPT 연동 → 대화 중 디자인 생성

다른 AI 대화창에서 바로 캔바 디자인을 만들고 고칩니다.

 12단계로 이동 🔒

저작권·공유 설정 → 안전하게 다루기

소재 저작권과 공유 범위, 학생 개인정보를 점검합니다.

 13단계로 이동 🔁

반복 업무 → 자동화로 굳히기

Bulk Create로 이름표·성적표 같은 자료를 한 번에 만듭니다.

 14단계로 이동

전체 단계 목록 다음 단계 · 가입과 화면 익히기

1. 반복되는 업무 찾아보기

지금까지 배운 것 중에서, 학기마다 혹은 매달 똑같이 되풀이하는 업무를 떠올려보세요. 평가계획서 작성, 시험문제 만들기, 채점, 학부모 안내, 과제 배포처럼 이름만 대상만 바뀌고 방식은 똑같은 일이 대부분입니다.

2. Gem에 템플릿 저장하기

3단계에서 만든 프롬프트 템플릿과 반복 업무 규칙을 14단계에서 만든 Gem의 지침에 저장해두면, 매번 새로 설명할 필요 없이 바로 불러 쓸 수 있습니다.

3. Apps Script로 한 단계 더 자동화하기

정말 반복적인 시트 작업은 제미나이에게 구글 Apps Script 코드를 요청해서, 버튼 하나로 실행되는 자동화까지 만들 수 있습니다.

프롬프트 예시

"이 시트에서 학생 이름을 학생1, 학생2…로 자동으로 바꿔주는 Apps Script 코드를 만들어줘. 어떻게 설치하고 실행하는지도 설명해줘."

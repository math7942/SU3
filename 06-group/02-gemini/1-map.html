1단계 · 제미나이로 무엇을 할 수 있나

제미나이는 구글 문서·시트·슬라이드, 클래스룸, 노트북LM처럼 이미 쓰고 있는 구글 도구 안에서 바로 불러 쓸 수 있다는 점이 가장 큰 특징입니다. 관심 있는 항목을 누르면 그 업무를 배우는 단계로 바로 이동합니다.

아직 제미나이가 낯설다면

먼저 2단계 — 가입과 화면 익히기로 시작해서 3단계 — 질문을 잘하는 법과 4단계 — 답을 검증하는 법까지 익힌 뒤, 아래 지도로 돌아와 필요한 업무를 골라 이어가는 것을 추천합니다.

📄

Google Docs 연동 → 평가계획서·수업계획 초안 작성

구글 문서 안에서 바로 초안을 만들고 그 자리에서 다듬습니다.

 5단계로 이동 📊

Google Sheets 연동 → 성적·통계 자동화

시트 안에서 함수·피벗·그래프를 제미나이가 직접 만들어줍니다.

 6단계로 이동 📽️

Google Slides 연동 → 수업 자료 제작

프레젠테이션 초안을 통째로 생성하고 이어서 다듬습니다.

 7단계로 이동 📝

프롬프트 작성 → 시험문제·채점기준 만들기

난이도별 문제와 배점 기준표를 함께 만듭니다.

 8단계로 이동 🔒

학생 자료 → 안전하게 다루기

개인정보 익명화와 구글 계정 공유 설정에서 주의할 점입니다.

 9단계로 이동 🖼️

이미지 업로드 → 서술형 평가 채점

손글씨 답안 사진을 올려 채점받고 근거를 확인합니다.

 10단계로 이동 📅

Gmail·Calendar 연동 → 안내문·일정 자동화

학부모 안내 메일 초안과 시험·행사 일정 등록을 자동화합니다.

 11단계로 이동 🏫

Google Classroom 연동 → 과제·피드백 배포

과제를 만들고 공지·피드백을 클래스룸에 바로 배포합니다.

 12단계로 이동 📒

NotebookLM 연계 → 학습 노트·오디오 요약

수업 자료를 모아 학생용 노트와 오디오 요약을 만듭니다.

 13단계로 이동 💎

Gems → 나만의 맞춤 챗봇 제작

우리 반 전용 채점 도우미 같은 반복 업무 전용 Gem을 만듭니다.

 14단계로 이동 🔬

Deep Research·확장 프로그램 → 심층 조사와 연결

최신 자료를 깊이 조사하고 다른 구글 앱과 연결해 씁니다.

 15단계로 이동 🔁

반복 업무 → 자동화로 굳히기

지금까지 배운 흐름을 학기 루틴으로 만들어 매번 재사용합니다.

 16단계로 이동

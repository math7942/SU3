1. 제미나이는 한글 파일을 바로 읽습니다

제미나이는 .hwp·.hwpx 파일을 첨부하면 별도 설정 없이 바로 내용을 읽습니다. 한글 프로그램이 설치되어 있지 않은 컴퓨터에서도, 채팅창에 파일을 끌어다 놓기만 하면 됩니다.

프롬프트 예시

"첨부한 가정통신문 파일의 내용을 한눈에 알아보게 요약해줘. 날짜와 준비물처럼 학부모가 놓치기 쉬운 부분은 따로 정리해줘."

2. 무엇에 활용할 수 있나

오탈자·형식 점검"맞춤법과 띄어쓰기가 어색한 부분이 있는지 확인해줘"처럼 요청합니다.
다른 대상에 맞게 다시 쓰기"같은 내용을 학부모가 이해하기 쉬운 말로 다시 써줘"처럼 요청합니다.

4. 학교 계정에서 첨부가 안 보인다면

워크스페이스 관리자 설정을 확인하세요

학교나 교육청에서 관리하는 구글 워크스페이스 계정은 관리자가 파일 업로드 기능을 막아뒀을 수 있습니다. 파일 첨부 버튼이 보이지 않는다면 관리자에게 Gemini 파일 업로드 기능 사용 가능 여부를 먼저 문의하세요.

5. 결과를 원본 문서에 반영하기

제미나이는 문서를 읽고 채팅창에 답을 텍스트로 보여줄 뿐, .hwp·.hwpx 파일 자체를 직접 고쳐서 돌려주지는 않습니다. 내용을 수정해야 한다면, 나온 답을 한글 프로그램에서 원본 파일에 직접 옮겨 적거나, 완전히 새 문서로 만들 거라면 5단계에서 배운 대로 Docs로 내보낸 뒤 필요하면 한글 파일로 다시 저장하세요.

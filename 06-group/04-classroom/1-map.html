Google Classroom 🏫

1단계 · Classroom으로 무엇을 할 수 있나

Classroom은 자료 배포, 과제·채점, 학부모 소통까지 수업 운영을 한곳에서 관리하는 도구입니다. 관심 있는 항목을 누르면 그 업무를 배우는 단계로 바로 이동합니다.

아직 Classroom이 낯설다면

먼저 2단계 — 가입과 화면 구성으로 시작해서 3단계 — 수업 자료·과제 올리기까지 익힌 뒤, 아래 지도로 돌아와 필요한 업무를 골라 이어가는 것을 추천합니다.

📌

주제(Topic) → 단원별로 자료 정리하기

수업 탭의 게시물을 단원별로 묶어 학생이 쉽게 찾게 합니다.

 4단계로 이동 🧮

성적 탭 → 루브릭·가중치로 채점하기

채점 기준표를 만들고 과제 유형별 가중치를 정합니다.

 5단계로 이동 💬

비공개 댓글 → 피드백 주고받기

학생 개인에게만 보이는 댓글로 의견을 주고받고, 재제출을 받습니다.

 6단계로 이동 🎯

Practice Sets → 자동 채점 연습문제 만들기

객관식·단답형 문제를 자동으로 채점하고 막힌 부분을 짚어줍니다.

 7단계로 이동 ✨

Gemini 연동 → 과제 초안·진행 상황 요약

과제 설명 초안을 받고, 학급 전체 진행 상황을 요약받습니다.

 8단계로 이동 👨‍👩‍👧

Guardian Summaries → 학부모 자동 안내

미제출·예정 과제를 학부모에게 정기적으로 자동 발송합니다.

 9단계로 이동 📅

Calendar 연동 → 마감일 자동 등록

과제 마감일이 구글 캘린더에 자동으로 표시됩니다.

 10단계로 이동 🧩

다른 도구 연동 → Docs·Sheets·Slides·Canva

다른 서비스에서 만든 자료를 과제에 바로 첨부합니다.

 11단계로 이동 📋

과제 현황 관리 → 필터·마감·리마인더

제출·미제출 학생을 한눈에 걸러보고 리마인더를 보냅니다.

 12단계로 이동 🔒

접근 권한 → 클래스 코드·개인정보 안전하게

클래스 코드 관리와 학생 개인정보 보호를 점검합니다.

 13단계로 이동 🔁

반복 업무 → 재사용으로 자동화하기

게시물 재사용, 클래스 복사로 학기마다 반복되는 일을 줄입니다.

 14단계로 이동

전체 단계 목록 다음 단계 · 가입과 화면 구성

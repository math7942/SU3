# 모의고사 검색 데이터

`01-mock-search.html`이 읽는 데이터입니다. 새 모의고사 PDF를 받으면 아래 순서로 추가합니다.

1. PDF 파일을 이 폴더에 둡니다. 파일 이름은 공백 없이, 예: `2026-09-mock.pdf`
2. PDF를 페이지별로 읽어 문항을 찾고, 문항마다 아래 형식으로 `<파일이름>.json`을 만듭니다.

```json
{
  "id": "2026-09-mock",
  "title": "2026년 9월 모의고사",
  "file": "2026-09-mock.pdf",
  "problems": [
    {
      "number": 14,
      "page": 7,
      "topics": ["합성함수", "함수의 극한"],
      "snippet": "두 함수 f, g에 대하여 합성함수 (g∘f)(x)가 ... 을 구하시오.",
      "answer": "③",
      "solution": "합성함수의 정의에 따라 g(f(x))를 계산하면 ..."
    }
  ]
}
```

- `page`는 PDF 뷰어 기준 1부터 시작하는 페이지 번호입니다 (검색 결과를 고르면 이 페이지를 통째로 렌더링해서 보여줍니다 — 같은 페이지에 다른 문항이 함께 있으면 함께 보일 수 있습니다).
- `topics`는 검색어와 비교할 단원·개념 키워드입니다. 학생들이 실제로 검색할 법한 단어를 넉넉히 넣어두세요 (예: "합성함수", "함수의 합성", "합성함수의 극한").
- `answer`·`solution`은 교사용 출력에만 쓰입니다. 학생용에는 나가지 않습니다.

3. `manifest.json`의 `exams` 배열에 `{ "id", "title", "file", "index" }`를 한 줄 추가합니다 (`index`는 2번에서 만든 JSON 파일 이름).

검색 페이지는 `manifest.json` → 각 `index` JSON → PDF 순서로 불러오므로, 이 세 가지가 맞아야 검색 결과에 나타납니다.

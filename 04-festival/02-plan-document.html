2단계 · 평가계획서 작성

학교마다 다른 평가계획서 hwp 서식을 그대로 살려, 내용만 채워 넣어 돌려받습니다.

1. 이 도구가 하는 일

완전히 새 문서를 만드는 게 아니라, 학교 양식에 {{ }} 표시를 한 번 넣어둔 "템플릿"을 만들어두면, 학기마다 그 자리에 값만 바꿔 채워주는 방식입니다. 표 위치나 항목명이 학교마다 달라도 이 방식이면 그대로 작동합니다.

.hwp(옛 버전)는 지원하지 않습니다

이 도구는 .hwpx 파일만 처리할 수 있습니다. 옛 버전 한글로 저장된 .hwp 파일이라면, 한글 프로그램에서 파일 → 다른 이름으로 저장을 열고 파일 형식을 HWPX로 바꿔 저장한 뒤 그 파일을 올려주세요.

2. 템플릿 만들기 (학교마다 한 번만)

  1. 학교의 평가계획서 hwp 파일을 한글 프로그램에서 엽니다.
  2. 매 학기 바뀌는 칸(과목, 학년, 평가 비율, 수행평가 내용 등)에 아래처럼 {{ }}로 감싼 이름을 직접 입력합니다.
  3. 파일 → 다른 이름으로 저장에서 파일 형식을 HWPX로 선택해 저장합니다. 이 템플릿 파일은 학기마다 다시 씁니다.
기존 칸에 있던 내용템플릿에 넣을 표시
수학Ⅰ{{과목}}
고등학교 1학년{{학년}}
70%{{지필비율}}
30%{{수행비율}}
다항식 문제 해결 포트폴리오 …{{수행평가내용}}

표시 이름은 자유롭게 정해도 됩니다. 아래 실습 도구의 표에서 왼쪽 칸(표시 이름)과 템플릿에 넣은 {{ }} 안의 글자를 똑같이 맞추기만 하면 됩니다.

실습

템플릿 채우기 도구

템플릿(.hwpx)을 올리고, 아래 표에 채울 값을 입력한 뒤 버튼을 누르면 {{ }} 자리를 값으로 바꾼 새 파일을 내려받습니다.

3. 내려받은 파일을 열기 전에

  • 한글 프로그램에서 열어 표 레이아웃이 그대로인지, 값이 원하는 칸에 들어갔는지 확인합니다.
  • 결과 상자에 "채워지지 않은 항목"이 남아 있다면, 템플릿의 {{ }} 이름과 표의 표시 이름이 다르게 적힌 것이니 맞춰서 다시 시도하세요.
  • 학교 결재 절차(공문 상신 등)는 이 도구와 별개로 그대로 따라야 합니다.

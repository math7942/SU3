AI가 배경을 지우는 법 — 배경 제거 체험

사진에서 사람만 남기고 배경을 지우는 AI의 4단계를 따라가 보세요!

3단계(분할 마스크)와 4단계(배경 제거 결과)는 실제로 브라우저에서 동작하는 TensorFlow.js 공식 사전학습 모델인 BodyPix(U-Net 계열 구조로 사람의 실루엣을 픽셀 단위로 구분하는 모델)를 사용합니다. 모델을 불러오지 못하면 배경색과의 색상 차이를 이용한 간단한 대체 방식으로 자동 전환되며, 화면에 어떤 방식이 쓰였는지 표시됩니다.

1단계(필터 수집)와 2단계(레이어 판단)는 실제 BodyPix 내부 값이 아니라, CNN이 여러 층을 거치며 "이 픽셀이 전경(사람)인지"를 판단해가는 과정을 간단한 컨볼루션 필터로 개념적으로 재현한 것입니다.

배경 제거 AI는 어떻게 동작할까?

영상 통화 배경 흐림, 인물 사진 배경 교체 같은 기능은 의미론적 분할(Semantic Segmentation) AI로 만들어집니다. 이 AI는 사진의 모든 픽셀 하나하나에 대해 "이 픽셀은 사람인가, 배경인가?"를 CNN으로 판단해서 마스크(가면)를 만들고, 그 마스크로 배경만 지웁니다.

모델을 불러오는 중...

🪄 배경 제거 4단계

1·2단계는 실제 내부 값이 아닌 개념적 재현입니다. 3·4단계는 이미지를 불러오면 실제 분할 모델(또는 대체 방식)로 계산됩니다.

이미지를 먼저 불러와 주세요.
